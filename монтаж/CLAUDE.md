# Монтаж разговорных видео (лицо в кадре)

Правила для всего, что в папке `монтаж/`. Общие правила канала — в корневом `CLAUDE.md`.
Распознавание речи и список вырезок — это техническая работа монтажа, она не заменяет работу `video-script` над сценарием.

## Инструменты
Ставятся скриптом `монтаж/установка.sh` (хук SessionStart запускает его сам, руками не нужно):
- Remotion 4 в `монтаж/remotion/` (react 18);
- faster-whisper (слова с таймкодами), ffmpeg, OpenCV, MediaPipe (трекинг лица для вертикальной версии);
- Chromium: `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`. `playwright install` не запускать.

Рендер Remotion всегда с флагами:
`npx remotion render src/index.ts <Композиция> <выход.mp4> --browser-executable=/opt/pw-browsers/chromium-1194/chrome-linux/chrome --chrome-mode=chrome-for-testing`

Заметки: `av` держим `<17` (иначе faster-whisper падает). Детектор лица MediaPipe: `монтаж/модели/face_detector.tflite`, после работы вызывать `.close()`.

## Где что лежит
- `монтаж/исходники/<ролик>/` — сырое видео и голос от владельца. В git не идёт.
- `монтаж/результаты/<ролик>/` — черновики 720p, чистовики 1080p, нарезка, аудио. В git не идёт.
- `монтаж/remotion/src/` — композиции Remotion (субтитры, акценты). В git идёт.
- `ролики/<ролик>/монтаж/` — текстовое: распознанная речь (json/srt), список вырезок, заметки, `передача.md`.
- Временное — в scratchpad сессии, не в корень.

## Большие видео
Видео и аудио в git не кладём (см. `.gitignore`). Передача файлов — через Google Drive: владелец кладёт исходник, Claude кладёт результат и пишет ссылку/имя файла в ответе. Не удалять и не перезаписывать файлы прошлых роликов, новая версия — новое имя (`_v2`, `_v3`).

## Порядок работы
1. Whisper → слова с таймкодами → список вырезок (паузы, «э-э», дубли) **текстом на согласование**. Ничего не режем до «ок».
2. FFmpeg режет и выравнивает звук (`loudnorm`, −16 LUFS).
3. Remotion накладывает анимированные субтитры и акценты.
4. Черновик 720p → после «ок» чистовик 1080p.

## Как общаться
- Правки показывать короткой вырезкой (несколько секунд вокруг места правки), а не всем роликом.
- Перед любым рендером коротко написать, что именно собираем: исходник, вырезки, разрешение, что накладываем.
- Список вырезок и итоги сохранять файлом в папку ролика и называть имя файла.
- Сценарий и транскрипты в чат целиком не выкладывать.
