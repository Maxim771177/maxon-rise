# С чего начать — канал Maxon Rise

1. Впиши конкурентов в `конкуренты.md` (или просто пришли список ссылок в чат).
2. Первое сообщение в новом чате:
   «Канал Maxon Rise. Конкуренты в конкуренты.md. Собери паспорт канала (этап 0).»
3. Claude через `video-script` соберёт транскрипты залетевших роликов и построит профиль сценариев,
   покажет его на утверждение. Потом — скрины конкурентов в `референсы/` и профиль стиля.
4. После утверждения паспорта — первый ролик: создать папку `ролики/01 - <название>/` с `идея.txt`.
